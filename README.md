# sts-first-maven

Apps live on their own branches (see the table in [`AGENTS.md`](AGENTS.md)):

- `homeguard/` on `claude/security-camera-mobile-app-kxp2a1` (agent docs on `claude/ai-docs-knowledge-base`): HomeGuard, a local-first Flutter security app (Android & iOS) for a Techson NVR, cameras, door station and indoor monitor.
- `flair_log/` on `claude/flair58-brew-logger`: Flair Log, a Flutter app that reads the Flair 58 pressure gauge with the phone camera, records a BOOKOO Bluetooth scale and graphs each shot.
- `piackereso/` on `ccr-8d9bb3c4-tgq8da`: Piackereső, a personal web app that searches Hardverapró, Jófogás, Vinted and Facebook Marketplace at once.

Working on the code (human or AI agent)? Start at [`AGENTS.md`](AGENTS.md). How-tos shared by all apps (e.g. [building a test APK](docs/build-apk.md)) are in [`docs/`](docs/).
